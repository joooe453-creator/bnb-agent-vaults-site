02

Agent

Your wallet owns the vault. The agent trades with its own key, inside the mandate.

Owner wallet any wallet via WalletConnect
Agent ERC-8004 agents owned by this wallet
Operator address replaces the agent's registered wallet
$ npx bnb-agent-vaults operator new  → creates a key in your system keychain and prints its address

The operator is the agent's own wallet from its ERC-8004 registration. It can only call execute inside this mandate and can never withdraw. You can pause it instantly; switching to a new key waits 24 hours. If its trades lose more than 2% of NAV against oracle prices within 24 hours, it pauses itself until you resume it.
